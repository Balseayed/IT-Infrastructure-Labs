# Windows Server Infrastructure Lab

This project documents my hands-on Windows Server infrastructure lab using VMware.

The lab covers core Windows Server administration tasks such as Active Directory, Group Policy, File Server permissions, Backup and Recovery, and basic infrastructure operations.

## Lab Sections

- [Active Directory](Active-Directory)
- [GPO](GPO)
- [File Server](File-Server)
- [Backup and Recovery](Backup-Recovery)
- [DNS](DNS)
- [DHCP](DHCP).

## What This Project Covers

- Domain Controller setup
- Active Directory users, OUs, and groups
- PowerShell bulk user creation
- Group Policy management
- File Server shared folders
- NTFS permissions
- Mapped network drives
- Backup and Recovery testing
- Client-side verification
